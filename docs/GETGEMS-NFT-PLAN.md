# KAVIXO NFT / Getgems preparation

The app includes a demo collectible gallery and sample TON NFT metadata templates.

Before minting:
1. Finalize collection and item artwork, supply, descriptions, attributes and royalty choices.
2. Replace placeholder IPFS image CIDs with permanent assets and validate all metadata.
3. Check Getgems' current creator requirements and TON NFT metadata standards.
4. Have an eligible adult project owner review collection contract, wallet ownership, marketplace terms and fees before mainnet actions.
5. Deploy and mint only through official Getgems flow and a wallet controlled by the collection owner.

This repository does not deploy a smart contract, connect a wallet, request signatures, mint NFTs, accept TON or perform mainnet transactions. The gallery collect button is local demo state only. 1 TON is not a guaranteed total fee; marketplace and network fees can change. Never put seed phrases or private keys in GitHub.
