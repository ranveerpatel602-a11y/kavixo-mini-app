# KAVIXO Mini App

Original black-and-gold Telegram mini-app prototype with virtual KXP points.

Run locally using `npm install` and `npm run dev`.

Includes virtual mining, energy regeneration, daily reward, missions, arcade placeholder, profile, wallet preview, NFT gallery and Getgems-ready metadata templates under `public/nft/`.

Demo only: no real token, payments, withdrawals, wallet connection, NFT minting or mainnet transactions are enabled. See `docs/GETGEMS-NFT-PLAN.md` before a future launch.
